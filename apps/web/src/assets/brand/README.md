# Crown and Blade brand assets

## Brand name

**Crown and Blade**

## Mark concept

The crown represents standard, confidence and finish. The narrow diagonal rust-red line is an abstract blade, not a literal razor. It gives the mark a purposeful edge without using generic barbershop imagery.

## Files

- `crown-and-blade-logo-dark.svg`: use on light or bone-coloured backgrounds.
- `crown-and-blade-logo-light.svg`: use in the dark header and footer.
- `crown-and-blade-mark.svg`: standalone mark for small light-background placements.
- `crown-and-blade-mark-light.svg`: standalone mark for dark placements.
- `crown-and-blade-favicon.svg`: browser icon and app icon source.

## Core colour tokens

- Ink: `#111111`
- Bone: `#F0EDE6`
- Burnt Rust: `#B54832`
- Concrete: `#5E5B56`

## Usage rules

- Use the light logo in the dark header/footer and the dark logo on bone backgrounds.
- Do not place the full logo over a busy photograph. Place it on a solid ink or bone surface.
- Keep a clear area around the mark equal to at least one third of its height.
- Do not add clipper, scissor, moustache, barber-pole, chrome, or neon imagery to the logo.
